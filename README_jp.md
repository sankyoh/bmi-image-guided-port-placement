# Procedural outcomes of image-guided central venous access port placement across the body mass index spectrum: a post hoc analysis of a prospective multicenter registry

画像ガイド下中心静脈アクセスポート留置におけるBMIと手技成績の関連を検討する、前向き多施設レジストリの事後解析用Stataコードです。上記は査読前の論文タイトルです。

本リポジトリには解析コードと変数表を掲載します。症例データは含まれません。

## 解析の概要

BMIをカテゴリ変数および連続変数として扱い、次のアウトカムとの関連を検討します。

| アウトカム | 変数名 | 解析時の定義 |
| --- | --- | --- |
| 二次成功 | `succ` | 0=一次成功、1=二次成功 |
| 留置時合併症 | `adevent` | 0=なし、1=あり |
| 手技時間 | `time` | 局所麻酔から閉創までの時間（分） |

主な解析は、BMIカテゴリ別の記述統計、ロバスト標準誤差を用いた修正ポアソン回帰によるリスク比、線形回帰による手技時間の平均差、および制限付き三次スプライン（RCS）による関連の可視化です。カテゴリ別解析では未調整・調整モデルを、RCSでは調整モデルを用います。効果量や予測値とともに95%信頼区間を出力します。

BMI 4分類・8分類の基準カテゴリは、いずれも18.5以上25未満の群です。手技時間のカテゴリ別解析はBMI 4分類を用い、RCSは連続値のBMIと4つのノットを用います。

調整変数は、年齢、性別、留置目的、外来・入院区分、抗菌薬使用、抗凝固薬使用、抗血小板薬使用、留置前30日以内のベバシズマブ使用歴です。変数の符号化は変数表、モデルへの投入方法は各解析ファイルを参照してください。

## 実行環境

- `version 19.5`に対応したStata環境（StataNow 19.5など）が必要です。一部の解析ファイルがこのバージョンを指定しています。バージョン指定の説明は[Stata公式マニュアル](https://www.stata.com/manuals/pversion.pdf)を参照してください。
- コードは`dtable`、`makespline`などのStata標準コマンドを用います。追加パッケージの導入処理は含まれていません。
- ファイルパスはWindowsでの使用を想定しています。他のOSで使用する場合は、パス区切りなどの確認・調整が必要です。

## データと再現に必要な準備

個人情報保護のため、入力Excel、症例単位のStataデータ、実行ログは公開しません。公開コードのみでは論文の数値結果を再現できません。実行には、利用権限のある入力データを別途準備する必要があります。

入力データには、変数表に記載した33変数を、**入力時のコード**で用意してください。解析時のコードに変換済みのデータを入力すると、再符号化が重複する可能性があります。`id`は欠損のない一意の文字列であることを前提とします。

公開版の`do/020_clean.do`では、症例ごとの入力値修正を省略しています。2026年9月19日の結果を再現するには、非公開の入力データのコピーを用い、当時の解析に必要な留置時合併症の訂正が反映されていることを確認してください。未反映の場合に限り、非公開の訂正記録に従って適用します。9月26日の血小板数・CRPの訂正は後日のデータ版に属するため、この再現では適用しません。訂正記録と準備済み入力は非公開で管理してください。

## 実行手順

1. 元の入力や既存の解析結果を保全するため、リポジトリの作業用コピーをローカルに作成します。そのルートに`data_raw`、`data_clean`、`log`、`output`の4フォルダを作成します。
2. 前処理を済ませた非公開のExcelを`data_raw/input.xlsx`として保存します。既定では先頭シートの2行目を変数名、3行目以降をデータとして読み込みます。変数名と入力コードは変数表に合わせてください。レイアウトが異なる場合は、作業用コピーの`do/010_import.do`で読み込み設定を変更します。
3. Stataで作業用コピーのルートに移動し、`master.do`を実行します。現在の作業フォルダを使うため、`000_config.do`のパスを書き換える必要はありません。

   ```stata
   cd "C:/analysis/port-bmi"
   do master.do
   ```

`master.do`は、取り込み → クリーニング → 記述統計 → カテゴリ別解析 → RCS解析の順に実行します。

解析結果は`output`、実行ログは`log`に保存します。

| --- | --- |
| `Table1.xlsx` | BMI 4分類別の記述統計 |
| `Risk_Ratio_bmi_cat_succ.xlsx` | 二次成功のリスク比 |
| `Risk_Ratio_bmi_cat_AE.xlsx` | 留置時合併症のリスク比 |
| `Mean_Time_Difference_bmi_cat.xlsx` | 手技時間の平均差 |
| `RCS_bmi_succ.dta` / `.gph` / `.png` | 二次成功の予測値と曲線 |
| `RCS_bmi_AE.dta` / `.gph` / `.png` | 留置時合併症の予測値と曲線 |

中間データとして`data_raw/df00.dta`と`data_clean/df01.dta`も生成します。再実行すると同名のデータ、ログ、出力ファイルを上書きします。

入力データ・中間データ・実行ログは非公開で管理してください。表や図を公開する場合も、その内容を確認してから追加してください。

## 検証状況・引用・ライセンス

Windows上のStataNow 19.5で、公開用コードを別の作業用コピーから実行しました。9月19日のBMI 4群別解析では、解析対象数、推定値、95%信頼区間が報告時の表示桁で一致しました。スプライン図3枚の予測値と95%信頼区間は、全BMIグリッド点で保存済みの数値出力と一致しました。数値の照合には9月26日保存分を用い、そのPNGが9月19日の図と画素単位で一致することを確認しました。
